### ⚡ Core Killer Features

* 🔀 **Next-Gen A/B Comparison:**  
  Revolutionary multi-mode split, wipe, and difference comparison engine designed to inspect multi-version shots like never before.

* 🚀 **Hyper-RAM Fast Caching:**  
  Instant, stutter-free playback pipeline engineered specifically for uncompressed 4K/8K cinema plates and multilayer EXRs.

* ✏️ **Live Onscreen Annotations:**  
  Precision frame-accurate visual markup toolset enabling interactive drawing, notes, and collaborative review right on the canvas.

* 🎨 **Native Cinema Color (OCIO):**  
  Full OpenColorIO support with 3-Way ASC-CDL and 3D LUTs ensuring 100% color fidelity from monitor to final theatrical grade.
